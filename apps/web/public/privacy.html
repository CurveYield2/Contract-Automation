Privacy policy

PreflightSim processes Solidity source code, project archives, public GitHub repository references, structured simulation workflows, RPC-derived blockchain state, and generated reports solely to perform requested compilation and simulation jobs.

Projects and results are stored in Cloudflare R2 and are intended to be deleted after 30 days through bucket lifecycle rules. GitHub Actions receives a job identifier and retrieves the project through an authenticated runner API. Submitted repository scripts are never executed.

Do not submit private keys, seed phrases, wallet credentials, personal data, or confidential projects unless you control and trust the configured Cloudflare and GitHub accounts. The API rejects known signing and broadcast fields but cannot classify every secret embedded in source comments.

No transaction is signed for or broadcast to a real blockchain. RPC endpoints are used as read-only state sources for disposable local forks.

Contact: protocol administrator at the contact address published by CurveYield.

API access keys entered in the browser interface are stored in session storage by default. The optional full-interface “remember key” setting uses local storage on that browser.
